# Un corazón para ti

Una página romántica hecha con React y Vite, lista para publicar en GitHub Pages.

## Música ambiental

La melodía es original y se genera en el navegador con tonos suaves, sin YouTube ni archivos externos. Pulsa la nota del centro del corazón para activarla o pausarla. Los navegadores requieren una interacción antes de permitir sonido.

## Desarrollo y publicación

```sh
npm install
npm run dev
npm run build
```

La acción de GitHub en `.github/workflows/deploy.yml` publica automáticamente al hacer push a `main`. En GitHub, habilita Pages usando **GitHub Actions** como fuente.
